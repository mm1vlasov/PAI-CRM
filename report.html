Как заполнить отчёт
Чтобы баллы засчитали без уточнений, проверь эти пункты перед отправкой.
  1. Укажи свои имя, фамилию и статик. Данные должны точно совпадать с игровыми.
  2. Для каждого выполненного пункта добавь ссылку на подтверждение. Одно выполнение = одна отдельная ссылка.
  3. Вставляй ссылки по одной на строку. Не смешивай несколько ссылок в одной строке.
  4. Проверь ссылки перед отправкой. Они должны открываться и показывать результат работы за эту неделю.
  5. Отправь отчёт на модерацию. Баллы появятся только после проверки и одобрения.
